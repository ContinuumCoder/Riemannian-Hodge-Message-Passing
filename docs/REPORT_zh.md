# RHMP v2：把"学习黎曼余链度量"做成可用的物理学习库 —— 工程、算法与理论升级报告

日期：2026-09-27 – 09-28（全部实验已完成）　代码：本仓库（`rhmp` 2.0.0）；实验在两台 GPU 服务器上完成（cab75：v2 各阶段；cab16：baseline 与部分各向异性实验），逐次运行的结果文件见 `results/cab75/`、`results/cab16/`，英文版报告见 `REPORT.md`。

## 1. 结论概要

1. **工程**：同硬件下 v2 比 v1 训练快 1.65–1.74×、推理快 2.8–2.9×、显存 −40%；稀疏算子快 2.6–7.6×；复形构建 100K 面 4.4 s → 8 ms；1M 格网格 v1 不可行、v2 每步 131 ms / 8 GB；变网格块对角 batch 比逐样本快 6–14×；1600+ 测试全过。
2. **正确性**：所有对称性（O(C)、E(n)、顶点重标号、面定向、规范变换、batch 组成）在训练后的模型上为机器精度（ΔR² ~1e-9）；d²=0 精确；‖L‖≤1 有证明与稠密校验。
3. **论文任务**（同脚本复评 v1，前 100 测试样本 R²）：T6 0.955→**1.000**、T7 0.653→**0.879**、T3 0.971→**0.996**、T1q **0.924**（v1 三角 0.918）、T2 0.913 vs 0.890（需显式隐藏场）、T5 0.676→**1.000**（T5g 求解器模式；通用堆栈 0.600）、T8 0.602 vs 0.47（见 §6.1 说明）。
4. **新能力**：跨网格/跨分辨率零样本迁移（T6f 在新网格 0.996–0.9999，4× 粗/细均 ≥0.9997）；变几何闭曲面 SURF 0.9967 且几何/拓扑（亏格 0/1 → 2）迁移无损（注：MGN 在 SURF 上 0.9997 且同样无损迁移，该任务不具区分性）；三维四面体、边/面余链 I/O、精确守恒 readout；异质 Poisson 4× 分辨率零样本迁移。
5. **算法升级（阶段二/三）**：预解式层把异质 Poisson 从 0.80 提到 0.91、各向异性从 0.76 提到 0.85；**求解器模式 + 学习张量度量：HP_k100 test R² 0.9999、4× 分辨率迁移 1.0000，仅 2K 参数**；冻结度量 + 真实材料参考不训练即复现 FEM（1.0000/1.0000）。
6. **度量 insight 的判定**：在通用堆栈里材料信息走特征通道、学到的度量与 σ 不相关（|r|≤0.3）；只有当架构就是"用 H 求解"（材料只进度量头 + 求解层）时，度量才被迫成为材料——这是可检验、已验证的结论；各向异性/高阶（1-form、2-form 质量矩阵）问题上对角度量在算子层面不可表示，张量度量必需（理论 §3.3，实例：T5 生成器的负权边只有张量度量能复现）。

## 2. v1 代码的问题与 v2 修复

| # | v1 缺陷 | 影响 | v2 修复 |
|---|---|---|---|
| F1 | 度量 = 逐格自由参数（n_k×8 基）+ 全局均值调制 | 不能跨网格/分辨率；依赖格编号；无几何意义 | 度量 = DEC 参考星 × 有界学习修正（局部不变量），无逐格参数 |
| F2 | batch 均值算度量 | 预测依赖 batch 组成（1K 格 4e-4，100K 格 7e-3） | 每样本度量，batch 无关（测试到 1e-6） |
| F3 | 度量无界、算子未归一化、nn.LayerNorm 破坏 O(C) | 深层不稳、条件数失控 | 有界 log 度量、每样本 Gershgorin 归一化 ‖L‖≤1、标量增益 RMS 与径向门控 |
| F4 | `local_rich` 用绝对坐标 | 破坏 E(n)，仅 2D | 只用不变几何量，2D/3D 通用 |
| F5 | 1-cochain lifting = sym+asym（非奇） | 不满足顶点重标号不变 | 严格奇的 lifting（奇线性 × 偶门控） |
| F6 | 输入只在节点；边场手工编码 (avg, avg·dx, avg·dy) | 破坏余链结构 | 任意阶原生输入/输出，连接模式精确规范不变 |
| F7 | d1·d0 校验稠密化 | 100K 网格 20 GB、6.5 s；1M 不可行 | 稀疏校验：100K 网格 8 ms |
| F8 | COO + 每次 .t()/.coalesce()、几何重复计算、permute 拷贝 | T6 一步 105 ms / 7.2 GB | CSR+预转置、(n,B,C) 零拷贝布局、几何缓存、块对角变网格 batch |
| F9 | 仅三角网格、0..2 阶 | 无法做体网格/一般 CW | 三角/多边形/四边形/四面体/网格，0..3 阶 |

**任务层面的发现**：v1 在 T1/T6/T7/T3 上的目标是伪标量/伪矢量（随面定向或反射变号）。严格反射与定向不变的模型不可能直接输出它们；v1 能拟合是因为逐格自由参数隐式破坏了对称性（记住了网格坐标系）。v2 把场放到正确的余链上（边连接 → 面通量），再用**无参数的定向映射**得到与 v1 完全一致的目标（映射精确到 7e-8）。v1 表中 MPSN/SCCNN/Clifford 的数字是**边空间 R²**（用边平均目标训练、在边空间评分），与节点 R² 不可比。

## 3. v2 算法

### 3.1 保留的 insight
固定 d_k（d²=0 精确）；所有可学习传播只经过 SPD 余链度量；O(C) 余链坐标系等变；E(n) 不变几何；阿贝尔规范不变。

### 3.2 度量：DEC 参考星 × 有界修正
H_m = ★_m · exp(ref_m) · exp(a·tanh(MLP(ψ_m)))，ψ_m 为 O(C)/E(n) 不变的局部量；上下块绑定（★ 与 ★⁻¹）；ref_m 为可选已知材料系数（原始物理 log 值）。初始化即纯 DEC。`learn_metric=False` 给纯物理先验。

### 3.3 归一化的度量 Hodge 算子（对称化 DEC 帧）
L_up = S^{-1/2} dᵀ H d S^{-1/2} / β（S_up=★_k，S_down=1/★_k），β 为每样本 Gershgorin 上界 ⇒ ‖L‖≤1；跨阶项用半算子 T = S^{-1/2} dᵀ diag(√(H/β))（TTᵀ = L̂，尺度无关 ⇒ 分辨率可迁移）；标量系数多项式滤波；径向门控。

### 3.4 阶段二：张量度量、预解式层、DEC 工具箱
* **Whitney 一致张量度量**：每个顶层单元一个 SPD 材料张量，余链度量 H₁ = Σ_f 单元块（Whitney 基、二次精确求积、fp64）。初始化 = Galerkin 星；d₀ᵀH₁d₀ = P1 刚度 = cotan Laplacian（≤1e-6）；四面体上 d₁ᵀH₂d₁ = Nédélec curl-curl。**阶段三修订**：原参数化 b·I + Σ a_k t_k t_kᵀ (a_k ≥ 0) 只能生成 M-矩阵（=对角度量的类），改为 σ_f = b·expm(Σ s_k t_k t_kᵀ)（有符号有界 s_k，覆盖全部 SPD）。
* **预解式层**：(I + τ_u L_up + τ_d L_down)⁻¹，批量 CG（Frobenius 内积 ⇒ 严格 O(C) 等变），条件数 ≤ 1+τ；隐式伴随梯度；热启动。
* **DEC 工具箱**：批量 CG、任意度量 Hodge Laplacian、Hodge 分解（环面 1/2/1、球 1/0/1 调和维数验证）、sharp/flat。
* **精确约束 readout**：`grad`（E = d₀φ，无旋精确）、`curl`（F = d₁a，规范不变）、`div`。

### 3.5 阶段三：让度量成为材料
* `material_dims`：材料列只进度量头（σ 影响输出的唯一路径是 H）。
* `layer_type='solve'` / 求解器模式：物理单位下 (S^{-1/2}A(H)S^{-1/2} + λI)⁻¹，Dirichlet/Neumann 处理，两级预条件子（64 次迭代残差降 ~1000×），线性 lifting/readout 由最小二乘初始化；**模型类恰含 FEEC 真解算子**。
* `--aux-pde`：算子辨识损失 ‖A(H)u − Mf‖²（对角度量下线性、凸）。
* 理论（`docs/THEORY.md`）：边电导可辨识、逐面张量只经其作用可辨识、对角度量 = M-矩阵子类、1-form/2-form 质量矩阵耦合只有张量度量能表示、β 归一化带来尺度规范。

## 5. 正确性、对称性、鲁棒性、迁移

* pytest（cab75，CPU+CUDA 全套，2026-09-28）：1770 通过、49 跳过、1 预期失败、0 失败：d²=0（所有构造器与批）、O(C)（整栈 1e-5）、E(n)、重标号、定向翻转、batch 无关（1e-6）、规范不变、‖L‖‖T‖≤1（稠密对照）、sliver 网格与极端输入无 NaN、fp64/fp32 一致、checkpoint 往返、指标与 v1 脚本一致 1e-6、v1 checkpoint 复评与论文一致 1e-5。

* 输入噪声：精确导数类映射（T6f、T3）对噪声放大明显（物理性质），T7f/T1 更稳。

## 7. 度量 insight 的判定（本轮最重要的结论）

1. **结构先行**：T6/T6f/T7f/SURF 上，精确 d²=0 + DEC 参考星已完成绝大部分工作（冻结度量 dec_fixed 两个 epoch 0.984，学习度量 0.9975）。度量的第一价值是"用 DEC 星做正确初始化 + 有界修正"。
2. **通用堆栈里度量 ≠ 材料**：σ 同时进特征/门控与度量头时，学到的 H₁ 与 σ 相关性 |r|≤0.3（多项式层甚至学成 Jacobi 预条件式的负相关，最强 −0.73），材料参考也几乎不改变精度——度量与特征通道可互换。
3. **架构 = 求解 ⇒ 度量 = 材料**：材料只进度量头 + 求解层后，学习张量度量在 HP_k100 达 0.9999、4× 分辨率迁移 1.0000（2K 参数），冻结真实材料时不训练即 0.99999999；**学到的 σ_f 与真实 σ_f 在物理单位下一致（r=0.996、斜率 1.04、截距 0.005，逐样本截距离散 0.006）**，而通用堆栈的度量与材料只有 |r|≤0.76 的混杂相关并带伪各向异性。
4. **各向异性/高阶是张量度量的必需场景**：求解器模式下张量 vs 对角：AHP_r100 0.964 vs 0.832、AHP_r10 0.992 vs 0.965、ASURF_r100（曲面）0.961 vs 0.823、ADARCYp_r100（三维）0.977 vs 0.919；对角度量 = M-矩阵子类；T5 生成器的负权边只有张量度量能复现（求解器模式：学习对角 0.464、冻结/学习张量 1.000）；1-form/2-form 质量矩阵的耦合项对角度量完全不可表示。H 构建的各向异性任务族（AHP 二维、ASURF 曲面纤维扩散、ACURL 三维 Nédélec curl–curl、ADARCY 三维 RT0 Darcy 面通量；`docs/ANISO_TASKS.md`）给出 **oracle 可表示性**（把真实张量代入各度量族的相对 L2 解误差，r=100）：

| 任务 | 对角星 | 旧锥张量 | 完整张量（范围 ≤5） |
|---|---|---|---|
| AHP r100（u） | 0.44 | 0.45 | **0.06** |
| ACURL r100（A / B） | 0.85 / 0.91 | 0.82 / 0.85 | **0.06 / 0.14** |
| ADARCY r100（面通量） | 0.76 | 0.64 | **0.09** |

旧锥参数化可表示的单元比例：二维 20%（r10）/2.6%（r100），三维 1%/0%。训练对照（求解器模式，30 epoch）：**AHP_r100 对角 0.832 / 4× 迁移 0.699 vs 完整张量 0.919 / 0.741**（张量版最佳在第 3 epoch 后震荡，已补跑更低学习率；度量恢复：对角边电导 r=0.918，张量边作用 r=0.901、面 log det r=0.44、各向异性比中位 49 vs 真值 93——方向/比值只部分恢复）；**ADARCYp_r100（三维各向异性 Darcy 压力）对角 0.919 / 0.866 vs 完整张量 0.977 / 0.970**（4K 参数）；**AHP_r10 对角 0.965 / 0.914 vs 张量 0.992 / 0.928**；ASURF_r100（曲面纤维扩散，通用堆栈+参考，50 epoch）对角 0.897 / 0.783 vs 张量 0.906 / 0.793（几何族测试 0.902–0.911）vs **冻结 DEC 星（dec_fixed）0.918 / 0.807**——通用堆栈里学习度量反而不如冻结先验，再次印证通用堆栈不把度量当材料；**求解器模式（30 epoch）：对角 0.823 / 4× 迁移 0.822 vs 完整张量 0.961 / 0.956**（几何族测试 0.951–0.967）——曲面纤维扩散上同样是"求解器 + 张量度量"最优（2K 参数）；ACURLb_r10（三维 Nédélec curl–curl，面目标，通用堆栈）对角 0.548 / 0.370，张量 0.585 / 0.393——两者都弱，该问题需要 1-form 求解层（当前求解层仅 0-form）；**AHP_r100 张量求解器（lr 3e-4，60 epoch）：0.964 / 4× 迁移 0.958**（对角 0.832 / 0.699）；通用堆栈（+参考，50 epoch）对角 0.593 / 0.449、张量 0.530 / 0.432——错位各向异性上通用堆栈明显不如求解器模式，且通用堆栈里张量无增益；MGN（50 epoch）0.665 / 0.400——v2 求解器模式 + 张量度量（0.964 / 0.958，2K 参数）大幅领先。度量恢复：张量的边作用 r=0.86–0.93、各向异性比中位 157（真值 93）/ r10 时 11（真值 9.4），面 log det r 仅 0.41–0.74——与理论一致：标量 Poisson 只能辨识边作用，逐面张量本身不可辨识。三维 r100 有可辨识性上限：每四面体 6 个张量分量 vs 约 1.3 条边的输入，边/面输入无法唯一确定张量（oracle 重建误差 52%）。
